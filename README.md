## ⚡ Core Value Proposition

* **Core Message:** `Recycle | Recovery | Refine — Extracting What Matters.`
* **Headline:** `Building Global Supply Chains of Critical Minerals & Rare Earth Elements.`
* **Strategic Milestone:** ₹350-Crore MoU with the Government of Karnataka for setting up a 230,000 sq ft refining infrastructure.

## 🛠️ Architecture & Tech Stack

| Layer | Technology | Details |
| :--- | :--- | :--- |
| **Framework** | **Astro 5** | Islands architecture delivering sub-second LCP and zero unnecessary JS |
| **Components** | **React 19 + TypeScript** | Strict type safety for interactive terminals and lead capture |
| **Styling** | **Tailwind CSS v4** | Custom corporate blueprint palette (`#0F2840` Navy, `#EE7B2B` Orange, `#2E87C6` Blue) |
| **Motion** | **Three.js + GSAP** | 3D wireframe planetary globe, particle clouds, and interactive 3D mouse parallax |
| **Security & Anti-Bot** | **Cloudflare Turnstile** | Enterprise bot management challenge + invisible honeypot trap |
| **Statutory Compliance** | **DPDP Act 2023** | Digital Personal Data Protection Act consent verification and audit logging |
| **API Gateway** | **PHP 8.4 / Node API** | Lead sanitization, IP rate-limiting, and encrypted JSONL ledger persistence |
| **CI/CD** | **GitHub Actions** | Automated build and deployment pipeline |
